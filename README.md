# 家庭库存管理微信小程序

这是第一版微信原生小程序代码，采用：

- 前端：微信原生小程序 + TypeScript
- 后端：微信云开发云函数
- 当前页面数据：先用本地缓存跑通 UI 和核心交互
- 云端提醒：已放入 `cloudfunctions/dailyReminder`

## 已实现页面

- 主页面：房子名称、搜索、位置分类、物品分类、物品卡片、导出清单、使用说明、新手教程
- 编辑页：添加/编辑物品、上传图片、选择位置/分类/单位、填写具体位置
- 物品详情页：图片、名称、位置、库存、周期、预计购买时间、价格区间、具体位置
- 账单页：购买记录，支持“价格从低到高”“价格从高到低”“时间由近到远”
- 周期页：按 `xxxx年xx月xx日` 展示最近两次购买时间、购买周期、下一次建议购买日期
- 我的页：头像、房子名称、功能入口、切换其他房子

## 当前规则

导出购物清单：

```text
预计购买时间 <= 5天 或 剩余库存 <= 2
先按剩余库存升序排序，若相同则按预计购买时间升序排序
```

导出格式：

```text
(1) 抽纸 剩余库存: 1 预计购买时间: 已到期
(2) 洗衣液 剩余库存: 2 预计购买时间: 还需3天
```

提醒清单：

```text
预计购买时间 <= 3天 或 剩余库存 <= 1
```

平台默认送达时间：

```text
京东：2天
淘宝：3天
拼多多：3天
线下超市：0天
其他平台：3天
```

第一版预测规则：

```text
购买周期 = 上次购买时间 - 上上次购买时间
预计用完日期 = 上次购买时间 + 购买周期
建议购买日期 = 预计用完日期 - 平台默认送达天数
```

## 使用方式

1. 用微信开发者工具打开本目录。
2. 导入项目时选择 `E:\store_wechatAPP`。
3. AppID 当前是 `touristappid`，如果要真机调试和云开发，请在 `project.config.json` 中换成你自己的小程序 AppID。
4. 开通微信云开发后，上传并部署 `cloudfunctions/dailyReminder`。
